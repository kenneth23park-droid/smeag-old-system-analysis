## 2. 주요 성과 상세

### 2-1. 메뉴 실작동 보강 — "메뉴가 실질적으로 안 되던" 문제 해결
- **원인**: 표 화면은 모두 `R.spec`을 거치는데, 데이터를 **①studentsFull 투영 ②크롤한 실테이블** 순으로만 찾고 둘 다 없으면 **"화면 명세(골격)" 정적 화면으로 폴백**. 레거시 크롤 시 **16개 테이블만 추출**되어 나머지 19개 메뉴가 명세만 표시됨(에러 아님).
- **해결**: **파생 데이터 계층(`specDerived`)** 추가 — 이미 임베드된 데이터로 실표를 계산. 페이지네이션·EXCEL 자동 적용.
- **실작동 전환(14개 + DORM STATUS)**

  | 메뉴 | 결과 |
  |---|---|
  | Graduate | 7,344건 |
  | 변경환불홀딩 / CHG-REF-HOLD | 각 2,061건 |
  | POPULATION2 · STDNT STATUS | 국적×캠퍼스 교차표 |
  | MC Report 2 | 캠퍼스×주차 매트릭스 |
  | REGISTER STATS | 등록월별 42개월 |
  | Deposit(test) · Pre-paid Info | 29건 |
  | FARM 리포트 / DAY IN&OUT | 19건 / 268건 |
  | VISIT(calendar) | 일자별 요약 |
  | DORM STATUS | **배치도 재사용**(실 캘린더) |

- **남은 5개는 의도적 무데이터**(가짜 데이터 생성 대신 사유 명시)
  - GAC BOARD · Campus Holding · SME_BOARD → 게시판 글 테이블 **미크롤**
  - DAYOFF / Scheduler → 스케줄러 테이블 **미크롤**
  - STDNT Fullsize/Encanto/Classic/Capital → 레거시가 홈으로 리다이렉트하는 **외부 에이전시 포털**(관리 기능 아님)

### 2-2. Group Students — 레거시와 동일
- Supabase `legacy.student_group_info`(**12건**) + `student_info.group_id` 학생수 + **그룹 멤버 실명단** 추출·임베드
- 레거시 동일 컬럼: `# · Group Name · Country · # of Students(View) · Status · Added by · Created · Action(EDIT)`
- 값 일치 확인: Test Group 1 **Korea 6명**, Group 2 Vietnam 1, Group 3 China 1, Opaw Currency Russia ×3 등 **12행 그대로**
- 기능: Group Name 검색 · EXCEL · **Add New Group** · **(View)** 학생명단 · **EDIT**(변경 확인 플로우)
- *(기존 임시 "국적그룹 파생"은 제거 — 실제 그룹 테이블이 별도로 존재했던 것이 원인)*

### 2-3. AGENCY PAGE (유학원 포털) 신설
- 메뉴: `Student's ▸ AGENCY PAGE (유학원 포털)` (외부포털 present2 메뉴도 연결)
- 레거시 재현: **히어로**(CLASSIC/CAPITAL/SPARTA 캠퍼스) + **MY PAGE 사이드바**(MY INFORMATION / STUDENT LIST / APPLICATION(등록신청) / LOG OUT)
- **STUDENT LIST(등록 조회 현황)**: 레거시 컬럼 17종(`NO·NAME·AGE·SEX·CENTER·COURSE·PERIOD·DORM·APPLY DATE·DEPARTURE·PAY DATE·INVOICE·LOA·FILE·PROCESS·Edit·Score`) + `(STUDENTS : N peoples)` + **UHAK ID·연도·월·NAME 검색 · EXCEL · 페이지네이션 · Edit(레거시 상세폼)**
- 실데이터: 2026년 **5,307명**, 유학원 `room` **1,088명** 등

### 2-4. 모바일 / 데스크톱 자동 분리 *(지적사항 반영)*
- **문제**: 폰으로 접속해도 루트(`/`)가 데스크톱을 띄우고 배너로 권유만 → 실제 분리 안 됨
- **조치**: 모바일 기기 감지 시 **`/m/` 자동 이동**, 모바일 "PC 버전"=`../?pc=1`(데스크톱 유지·리다이렉트 루프 방지)
- 검증: 데스크톱→유지 / iPhone→`/m/` / iPhone+`?pc=1`→데스크톱 ✔

### 2-5. AGENCY 항공/픽업 등록 — **출발일 7일 전 마감 규칙**
- STUDENT LIST `FILE`열 **✈ 버튼**(등록가능=녹색 / 등록완료=✓)

  | 상황 | 동작 |
  |---|---|
  | 오늘 ≤ 출발일−7일 | 입력·저장 **활성**, "마감일 ○○까지 등록 가능" 안내 |
  | 출발일−7일 경과 | 입력창·저장 **비활성** + **"⚠ 등록은 출발일 기준 일주일 전입니다"** 안내(마감일·매니저 문의) |
  | 출발일 미정 | 비활성 + 안내 |
  | 마감일 당일 | 활성(경계 포함) |

- 마감일 표시를 **로컬(KST)** 기준으로 계산 — UTC 하루 밀림 버그 수정

### 2-6. AGENCY 등록신청(APPLICATION) 실연결
- **문제 1**: 제출해도 토스트만 뜨고 실제 등록 안 됨 → **확인 → 실제 학생행 등재(승인대기 `waiting`) → STUDENT LIST 즉시 표시**, 종료일=시작일+기간(주) 자동계산
- **문제 2**: 유학원 드롭다운이 `DICT.uhak`(크롤 49개)라 **실제 uhak_id(room·cesa·blued…)와 불일치** → **실 studentsFull 값·건수순으로 생성**(예: `room (2449)`) → 검색·등록 모두 실데이터 연결
