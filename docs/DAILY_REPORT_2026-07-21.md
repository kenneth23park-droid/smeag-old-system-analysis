## 2. 주요 성과 상세

### 2-1. 전 메뉴/화면 영어화 — 대표 요청사항
- **런타임 번역 계층** 도입: 정확일치 사전 **294항목**(병렬 번역 작업) + 동적 패턴 규칙(전체/결과·년월·건/명/실/주 등) + **MutationObserver**로 모달·팝업까지 자동 번역
- **전 메뉴 순회 검증** 결과 UI 잔여 한글 **4건**(사소한 안내문)까지 감소
- **학생 이름·유학원명 등 데이터는 원문 유지**(사전 정확일치 방식 → 오번역 없음)
- 상단 **EN / 한 토글**(기본 영어, 선택 브라우저 저장)

### 2-2. 로그인 흐름 개선
- **비밀번호 변경 강제 화면 제거** — 로그인 즉시 진입(폴백·Supabase 양쪽 경로), `must_change` 플래그 전 계정 해제
- **레거시 관리자 7명 로그인 허용** — 기존엔 데모 4계정만 등록돼 `katie`·`cebusme2` 등이 거부됐음. 로그인 목록에 실제 관리자 추가(데스크톱·모바일) → **anon 키 없이도** 실제 아이디로 로그인
- 검증: `katie` `cebusme2` `admin1` 모두 즉시 진입

### 2-3. 학생리스트 조작 방식 정리
- **행 클릭 팝업 제거** → 작업은 **오른쪽 ACTION 버튼**(수정·변경·연장·상담·약식)으로 일원화
- **이름 복사 가능**(드래그 선택) + 잘려도 전체 이름은 DOM 보존·툴팁 표시
- *(참고: 금일 22일, 요청에 따라 이름 클릭 시 상세정보 열기로 재조정)*

### 2-4. 레거시 표 타이포 조건 반영
실제 레거시(`student_list.php`)에 로그인해 **브라우저 계산값을 직접 측정** → 신전산 리스트에 동일 적용.

| 항목 | 레거시 실측 → 신전산 적용 |
|---|---|
| 폰트 | **Tahoma, 굴림** |
| 데이터/헤더 | **11px · weight 400 · #222** |
| 행 높이 | **30px** |
| 정렬 | **가운데**(AGENCY 첫 컬럼만 좌측) |

- 미성년 빨강·상태 pill·캠퍼스 칩 등 업무상 필요한 표시는 유지

### 2-5. 한 페이지 맞춤 (레이아웃 버그 수정)
- **원인**: 고정(freeze) 레이아웃의 `min-height:0` 때문에 화면이 짧거나 **확대(zoom) 상태에서 행 영역이 0으로 눌려 헤더만** 보였음
- **수정**: 행 영역 최소 높이 확보(항상 최소 8행) + 날짜 `YY-MM-DD` 축약(전체는 툴팁) + 폭 축소
- **결과**: 1000~1500px 전 구간 + **확대 150%까지 가로스크롤 없음**

| 화면 | 결과 |
|---|---|
| 1500 / 1400 / 1280px | 가로스크롤 없음 ✅ |
| 확대 135% / 150% | 가로스크롤 없음 ✅ |
