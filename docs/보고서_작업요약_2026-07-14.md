| room_info / room_list | 1,127 / 2,797 | 방 마스터 |

### ⚠️ 실패 → 원인 규명 완료 (7개 테이블)
- **student_info(학생 마스터), student_info_history** 외 5개
- **근본 원인:** 구버전 변환 코드가 신규 DB 제약조건에 **빈 값('')과 SET 조합값**을 허용하지 않아, 한 행이라도 걸리면 테이블 전체가 롤백됨
- **해결:** 변환 코드는 **이미 수정 완료**(작업 트리 반영). 원본 MySQL은 **일절 건드리지 않음**(무손실·단방향 원칙 준수)
- **남은 작업:** 수정된 코드로 **7개 테이블만 재적재** → 이후 학생 명단·배치도에 실제 데이터 연결 (예상 복구: 학생 마스터 90,524행 등)

> 진단은 **병렬 오케스트레이션(8개 에이전트 동시 분석)** 으로 신속 수행했습니다.

## 3. 신규 관리자 UI 프로토타입

레거시 관리자 화면 40여 종을 실제 크롤·분석하여, 현대적 신규 관리 콘솔로 재설계했습니다.

### 전체 메뉴 골격 (실측 반영)
- **Record / Student's / Dormitory / Cash Cards** 4개 대분류, 40+ 하위 메뉴
- 상단 **드롭다운(탑다운) 네비게이션** — 카테고리 클릭 시 메뉴 펼침

### 핵심: 기숙사 현황 배치도 (레거시 room_stat3.php 재현·고도화)
- **방 × 일자 캘린더** — 성별 색상, 입실·퇴실·홀딩·방변경 마커
- **±6개월(13개월) 뷰** — 년/월 표시, 월 클릭 시 **해당 월 중앙 정렬 + 좌우 스크롤**
- **틀 고정** — 좌측 방번호/인실/이름 + 상단 날짜 헤더 고정, 표 자체 스크롤
- **대용량 대비** — content-visibility 기반 가상화로 **1,127실 규모** 대응 설계
- **셀 클릭 → 업무 액션** — 입실 / 퇴실 / 방배정 / 방변경 / 홀딩 / 빈방
- **ROOM REPLACEMENT 모달** — 방변경 클릭 시 학생정보 + 예약정보 + 후보 방목록(MOVE) 원스톱 처리 (레거시 reserve_move.php 재현)

### 실데이터 반영
- 유학원(48곳)·국적·캠퍼스·상태·코스 등 **실제 옵션값**을 필터에 연결

### 운영 안정성 장치
- **전체화면 모드**(주소창까지 숨김), **다크/라이트 테마**
- **중복 실행 방지(멱등)** — 저장·인보이스 발행 더블클릭 차단 데모
