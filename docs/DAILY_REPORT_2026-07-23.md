## 3. 주요 성과 상세

### 3-1. 레거시 잔여 메뉴 완성 (00:42~00:59)
- 상단 카테고리 3개 신설: **Member's**(회원/포인트/접속자) · **Agency**(목록/커미션/방문/통계) · **Financial**(등록금·인보이스/코스/학비)
- **부서별 권한(RBAC)**: 5부서 × 카테고리 매트릭스 + 사이드바 필터 + 접근가드
- **Financial 4변형**(한국 5,139 / 외국 7,011 / 연장 279 / 변경환불홀딩 1,782), **Agency 통계 3종**(유학원×캠퍼스, 유학원×국적)
- 인보이스는 기존 4중 멱등 방어 + PDF 생성 유지

### 3-2. 배치도 레거시 재현·UX (09:44~13:49) — 당일 최다 집중
- **구분(그룹) 필터** 신설(성별↔룸타입 사이): CAPITAL1~4·S hotel·Amethyst·Canberry 등 그룹 전체명 선택, 센터·성별 연동
- **가로 스크롤 시 이름 실시간 갱신**: 보고 있는 시점의 점유자로 이름칸이 자동 전환(레거시 전개 규칙 동일). 이름↔패턴 매칭 감사 4,002건 불일치 0
- **레거시 밀도화**: 셀 폭 22→19px·행 26→21px·헤더 진하게, 구분선/X 진하게 → 레거시 표와 근접
- **틀고정 강화**: 이름열 고정 경계 그림자, 하단 오클릭 방지 여백 sticky 고정
- ALL 옵션 순서 정리, 구분 드롭다운 라벨 반복 조정(요청 반영)

### 3-3. 모바일 대폭 확장 (14:11~17:55)
- 배치도에 데스크톱과 **동일한 그룹 필터** 추가(센터 분류를 desktop과 일치시켜 Amethyst/Canberry→CAPITAL 정합)
- **데스크톱 전체 메뉴(7카테고리·약 60항목)** 를 모바일 More 메뉴에 반영(전용 렌더러 없으면 표 폴백)
- **언어 기본 영어화**: 런타임 번역 계층 이식(사전+규칙+복합노드 안전치환+MutationObserver) + EN/한 토글. 학생·유학원 **이름 데이터는 원문 보존**

### 3-4. 에이전시·재무 로직 (19:02~19:37)
- **출발일 등록 마감**: 마감 = 출발일 1주일 전 금요일. 임박 출발일 선택 차단(min) + 마감 지난 입력 시 빨강·⚠안내·등록 비활성. 안내문 "출발일 등록은 출발일 일주일전 금요일까지오니 필히 등록바랍니다."
- **커미션 규칙(합산 모델)**: `COM = 학비×나라정율% + 코스정액$ + 빌딩정액$`. 편집 가능한 설정화면(나라/코스/빌딩) 신설 → 학생 COMMISSION INFO·인보이스에 자동 반영
- **COURSE 다중필터**: 텍스트 입력 → 체크박스 드롭다운(코스명+코드, 검색·전체해제)

### 3-5. 배치도 심화 (20:26~20:47)
- **방 이동경로(ROOM MOVE PATH)**: 학생의 방 점유 이력을 시간순 복원 → 경로칩(→)+기간 테이블 (예: CAPITAL1 302 → 304)
- **이름 최대 2줄 전체표시**(기존 1줄 말줄임 → 2줄 클램프)
- **이름 KOR(한글명) 표시**: EN→KOR 매핑(한글명 3,018건), 표시만 한글·클릭용 data-name은 EN 유지
